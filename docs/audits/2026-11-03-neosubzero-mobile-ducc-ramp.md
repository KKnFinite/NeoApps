# NeoSubZero mobile DUCC ramp view

Starting main/origin/main: `a4b7503cdd8f16cba7a0e21d6c5cc9f64a40296f` (2026-11-03).

## Presentation changes

- Mobile DUCC (`/neosubzero/ucc`, up to the existing 900px mobile breakpoint) has STAFFING / RAMP VIEW controls. STAFFING keeps the existing staffing workspace. RAMP VIEW shows one selected Alpha, Bravo, Charlie, Delta, Echo or Remote ramp.
- The existing `_ucc_board.html` physical-ramp macro and canonical server projection are reused. There is no duplicate aircraft list, movement engine, queue calculation, mutation endpoint or permission grant. Parking, Position 10, Middle, Position 9, capacity/location/conflict warnings and selectable aircraft information retain their existing identities and behavior.
- The selector uses two compact rows on phones. Main ramps retain the desktop three-column physical geometry; Remote uses two parking columns. No staffing editors, fluid-prep panel, observation/forecast presentation or weather controls are displayed in mobile RAMP VIEW.
- The selected view/ramp stay in the existing page root through both full and draft-deferred live refresh. View-only query parameters preserve them through reload as well. Switching views does not submit, discard or transfer a draft and adds no requests or polling timer.
- Authorized mobile Coordinators receive a RAMP VIEW link beside AIR-TO-GROUND SCRIPT. It opens the current Coordinator ramp. BACK TO COORDINATOR follows the ramp selected on DUCC. Links respect existing destination view/edit permissions; routes and mutation permissions remain unchanged. Desktop Coordinator retains its layout.
- DUCC's ambient layer, weather-dependent theme classes and AMBIENT MOTION control/handler are temporarily removed. Factual observation/forecast information remains in the existing desktop and mobile STAFFING presentation. Weather services, saved preferences and preference endpoints, FROST, observations, archive records and historical weather are unchanged, allowing later restoration.
- The shared SubZero workspace CSS and DUCC script URLs use `20261103-mobile-ramp-v1` cache versions. No database/model/service/configuration changes are included.
